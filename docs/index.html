PDF tools that never upload your file

Six small tools for documents. Every one of them works without sending your file anywhere.

🔒Private by construction. Every tool here runs either inside your browser or on your own machine from a terminal. There is no upload step, no account and no server to trust — which matters most for the two documents you would least want to hand over: your signature, and a file whose redaction might have failed.

Why it is built this way

Most tools that do these jobs ask you to upload the file first. For a signature, or for a document you are checking precisely because its censorship may have failed, that is the wrong shape: you would be handing a stranger the exact thing you are trying to protect.

So the redaction check runs in the browser through pdf.js, and the rest are Python scripts you run yourself. You can disconnect from the network after this page loads and the checker still works.

Install the command-line tools

git clone https://github.com/wilwork-de/scanfix.git && cd scanfix
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
